Сервер ИИ

Запросы будут уходить на выбранный адрес. Принимаются только локальные адреса и частные сети школы (localhost, 10.x, 172.16–31.x, 192.168.x) — облачные сервисы по политике 152-ФЗ не подключаются.

Без пути /v1 — он добавляется автоматически. Пример: http://192.168.0.19:1234

Модель

Список моделей заполняется кнопкой «Проверить». Выбор применяется сразу и запоминается при сохранении.

0
Случайность ответа. 0 — строгое распознавание (рекомендуется), выше — разнообразие формулировок.
1
Сэмплирование. 1 — без отсечения (по умолчанию).
