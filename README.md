# 📑 DocAI Assistant
> **Локальное приложение на базе искусственного интеллекта для автоматизации обработки рукописных школьных документов и ведения Excel-отчетности.**
> Индивидуальный итоговый проект по информатике за 10 класс.

---

## 🔒 Локальная обработка
Приложение рассчитано на работу с локальной мультимодальной нейросетью через **Ollama** или сервером в разрешённой частной сети. При подключении к внешнему адресу персональные данные могут покинуть локальный контур; используйте только доверенный сервер.

---

## 🚀 Быстрый запуск

### Web-версия

Проект разделён на три слоя:

* `web/` — React-интерфейс для загрузки документа, просмотра результата и подтверждения исправлений;
* `compiler/` — FastAPI-контур, принимающий документ и возвращающий JSON;
* ядро Python (`document_loader.py`, `field_locator.py`, `extractor.py`, `validator.py`, `reference_dictionary.py`, `excel_manager.py`) — OCR/VLM, проверки и экспорт.

Во время одиночного и пакетного распознавания Web-интерфейс показывает модальное окно с текущим этапом и индикатором прогресса.

Установите зависимости компилятора и веб-API:

```bash
pip install -r requirements-web.txt
```

Запуск:

```bash
./run.sh
```

Откройте `http://127.0.0.1:5173`. API компилятора работает на `http://127.0.0.1:8000`.

PP-OCRv6 подключается при наличии совместимой сборки PaddlePaddle. На macOS Apple Silicon с Python 3.14 может понадобиться отдельное окружение Python 3.10–3.12; без него API автоматически использует VLM.

Старый интерфейс CustomTkinter удалён. Python-код теперь не отвечает за отображение страниц.

### Подключение к Ollama:
* По умолчанию используется LAN-сервер `http://192.168.0.19:1234`.
* Если модель запущена на другом компьютере, перед запуском задайте `DOCIA_OLLAMA_HOST` с нужным адресом.
* Модель можно выбрать через `DOCIA_MODEL`; по умолчанию используется `qwen2.5-vl:7b`.
* После запуска список моделей сервера появляется в поле «Модель ИИ».

## 🛠 Возможности системы

1. **Одиночный документ с верификацией (Human-in-the-Loop):**
   * Поддержка изображений (`.png`, `.jpg`, `.jpeg`) и PDF-документов (`.pdf`).
   * Адаптивная предобработка сканов: повышение контраста и резкости для четкого считывания шариковой ручки.
   * Просмотр документа слева и редактируемые поля справа: возможность проверить данные перед сохранением.
   * Выбор приоритета `OCR + VLM`, только PaddleOCR-полосы или только VLM.
   * Выбор детектора PP-OCRv6 medium/small.
   * Подтверждение исправлений справочника прямо в браузере.

2. **Компилятор:**
   * PaddleOCR находит точные координаты печатных меток и полос рукописных строк.
   * VLM получает увеличенный crop с исходными координатами, а при недоступности OCR использует резервную геометрию.
   * Валидатор проверяет даты, телефоны, СНИЛС и совпадение фамилий.
   * Пакетный режим принимает до 50 документов и возвращает отдельный результат для каждого файла.
   * Результаты пакетной обработки скачиваются единым Excel-файлом.

3. **Ограничение:**
   * Для PDF пока обрабатывается первая страница; остальные страницы будут добавлены отдельным этапом.
