# Отчёт по безопасности

## Область обработки

Документ и персональные данные передаются из React только в локальный FastAPI-компилятор. Компилятор обращается к Ollama по `DOCIA_OLLAMA_HOST`. По умолчанию разрешены localhost и частные RFC1918-сети; публичные адреса блокируются в `DocumentExtractor._clean_host`.

## Реализованные меры

* PDF ограничен 20 страницами, растровое изображение — 25 млн пикселей.
* Загруженные изображения проверяются через Pillow перед обработкой.
* API не сохраняет входной Base64 или временные изображения на диск.
* Результаты перед записью в Excel очищаются от управляющих символов и Excel-инъекций (`=`, `+`, `-`, `@`).
* Справочник принимает исправления только после нажатия пользователем кнопки «Добавить».
* CORS разрешает только локальные адреса React dev-сервера.
* Адрес сервера ИИ задаётся конфигурацией `DOCIA_OLLAMA_HOST` либо отдельным приложением настроек; DNS-имя принимается только после проверки, что оно разрешается в частный LAN-адрес.
* Приложение настроек (`GET /settings`) отдаётся самим компилятором (same-origin, без отдельного CORS) и подчиняется той же проверке адреса `_clean_host`: публичные адреса сохранить нельзя. Настройки пишутся в `settings.json` (файл в `.gitignore`). Опциональный API-ключ OpenAI-совместимого сервера хранится только в этом локальном файле, в ответах API маскируется (`sk…d`) и не попадает в логи.
* Логирование PII-safe (`logging_utils.py`): в журнал не попадают значения полей, содержимое документов и имена исходных файлов (могут содержать фамилию). Каждая запись несёт correlation id; уровень и файл лога задаются `DOCIA_LOG_LEVEL` / `DOCIA_LOG_FILE`.
* **Авторизация с ролями (оператор / администратор).** Внешних эндпоинтов нет: публичны только `/api/health` и `POST /api/auth/login`; всё остальное требует Bearer-токен. Права и обязательная смена временного пароля проверяются на сервере (FastAPI-зависимости, 401/403), а не только скрытием кнопок в UI. Консоль `/settings` — только для роли `admin`.
* **Пароли и сессии:** PBKDF2-HMAC-SHA256 (600 000 итераций, случайная соль на пользователя), сравнение через `hmac.compare_digest`. Сессии — случайные opaque-токены `secrets.token_urlsafe(32)` в SQLite `docia.db`, скользящий TTL 24 ч; токен отзывается при выходе, сбросе пароля и блокировке. Логины сравниваются без учёта регистра (включая кириллицу).
* **Защита от перебора:** 5 неудачных попыток подряд за 15 минут → блокировка входа (`429`).
* **Журнал активности (PII-safe) в `docia.db`:** только `username`, `action`, отметка времени, `ok`, `elapsed_ms`, `model`/`backend` и счётчики. Имена файлов и значения полей не логируются. Файл `docia.db` в `.gitignore`.
* **Сегрегация обязанностей:** оператор видит только обработку документов; учётные записи, адрес/модель сервера ИИ и статистику меняет только администратор. Администратор не может заблокировать или удалить собственную учётку (400).
* Папка тестовых образцов `test_samples/` добавлена в `.gitignore` — обезличенные сканы не коммитятся в репозиторий.
* Старый Python GUI удалён, поэтому в Python-коде нет локальных окон, открытия внешних путей или shell-вызовов из интерфейса.

## Границы ответственности

Безопасность локального контура зависит от настроек Ollama, операционной системы, прав на файл Excel и сетевого экрана. Перед эксплуатацией нужно ограничить доступ к порту API, хранить журнал Excel в защищённой папке и использовать только обезличенные тестовые сканы.

## Открытые задачи

* Первый админ логинится `admin/admin` и обязан сменить пароль при первом входе — проследить, чтобы смена действительно была выполнена до передачи системы классу.
* В режиме класса (несколько ПК, HTTP в школьной сети) пароль учёток администратора передаётся по сети открыто. При выходе за пределы доверенной сети или для удалённого администрирования — включить HTTPS (например, reverse-proxy с сертификатом) и не открывать порт `8000` наружу.
* Проверить политику хранения и удаления временных файлов в окружении конкретной школы.
* Защита от повторного ввода действует только внутри текущей пачки (см. `GAPS.md`): журнал активности в `docia.db` содержит только обезличенные счётчики, а не содержимое документов — для сверки между выгрузками нужен отдельный механизм.
