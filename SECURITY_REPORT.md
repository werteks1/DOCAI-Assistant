# Отчёт по безопасности

## Область обработки

Документ и персональные данные передаются из React только в локальный FastAPI-компилятор. Компилятор обращается к Ollama по `DOCIA_OLLAMA_HOST`. По умолчанию разрешены localhost и частные RFC1918-сети; публичные адреса блокируются в `DocumentExtractor._clean_host`.

## Реализованные меры

* PDF ограничен 20 страницами, растровое изображение — 25 млн пикселей.
* Загруженные изображения проверяются через Pillow перед обработкой.
* API не сохраняет входной Base64 или временные изображения на диск.
* Результаты перед записью в Excel очищаются от управляющих символов и Excel-инъекций (`=`, `+`, `-`, `@`).
* Справочник принимает исправления только после нажатия пользователем кнопки «Добавить».
* CORS разрешает только локальные адреса React dev-сервера.
* Адрес сервера ИИ задаётся конфигурацией `DOCIA_OLLAMA_HOST`; DNS-имя принимается только после проверки, что оно разрешается в частный LAN-адрес.
* Старый Python GUI удалён, поэтому в Python-коде нет локальных окон, открытия внешних путей или shell-вызовов из интерфейса.

## Границы ответственности

Безопасность локального контура зависит от настроек Ollama, операционной системы, прав на файл Excel и сетевого экрана. Перед эксплуатацией нужно ограничить доступ к порту API, хранить журнал Excel в защищённой папке и использовать только обезличенные тестовые сканы.

## Открытые задачи

* Добавить авторизацию, если API будет доступен за пределами одного компьютера.
* Добавить журналирование ошибок без записи исходных персональных данных.
* Проверить политику хранения и удаления временных файлов в окружении конкретной школы.
