# Локальный справочник

Добавляйте по одному значению на строку в `surnames.txt`, `first_names.txt`,
`patronymics.txt`, `cities.txt`, `organizations.txt` и `profiles.txt`.
Пустые файлы не обязательны: встроенный набор значений используется всегда.

Для подтверждённых исправлений можно заполнить `custom_corrections.csv`:

```csv
category,wrong,right
surnames,Бодров,Бобров
organizations,ГУСД,РЖД
```
