# Замер точности распознавания (CER/WER)

Скрипт [evaluate.py](../evaluate.py) замеряет, насколько распознанные значения полей
совпадают с эталоном, набранным вручную. Результат — аргумент для слайда
«точность распознавания».

## Метрики

Для каждого поля сравниваются нормализованные значения:

- **CER** — редакционное расстояние Левенштейна, делённое на длину эталона
  (по символам).
- **WER** — то же расстояние, но по словам.
- **exact** — значения совпали полностью после нормализации.

Нормализация зависит от поля:

| Поле | Нормализация |
|---|---|
| СНИЛС, телефон, паспортные данные | только цифры (`123-456-789 00` == `12345678900`) |
| Остальные | нижний регистр, ё→е, схлопывание пробелов |

0.0 — идеальное совпадение. Чем ближе к нулю, тем точнее распознавание.

## Раскладка данных

Папка `test_samples/` **не коммитится** (в `.gitignore`) — в неё кладут только
**обезличенные** сканы без ФИО реальных людей. Эталон-разметка тоже приватная.

```
test_samples/
├── 2023_01.png          # имя файла = кейс (любой, но уникальный)
├── smith.jpg
├── smith.pdf            # можно многостраничный PDF
└── labels/
    ├── 2023_01.json     # эталон именуется по имени файла без расширения
    └── smith.json
```

Формат эталона `labels/<case>.json`:

```json
{
  "fields": {
    "ФИО поступающего ученика": "Иванов Иван",
    "Дата рождения ребенка": "01.02.2010",
    "СНИЛС поступающего": "123-456-789 00"
  }
}
```

Поля должны называться так же, как колонки бланка. Сравниваются только поля,
перечисленные в эталоне. Если поле на бланке пустое — поставьте пустую строку
`""`, и значение модели будет сравниваться с ней.

## Запуск

Нужен доступный сервер ИИ (Ollama/LM Studio), как для обычного распознавания.

```bash
venv/bin/python evaluate.py                # весь набор, отчёт в stdout
venv/bin/python evaluate.py --limit 3      # первые три документа
venv/bin/python evaluate.py --out report.md
```

Пример вывода (фрагмент):

```
Документов в замере: 5
  • smith.png …
      CER 0.0210 · WER 0.0500 (9/10 полей точно)
```

Итоговый отчёт пишет средний CER/WER и долю точно распознанных полей по набору.

## Как собрать набор

1. Возьмите сканы бланков, **удалите/замажьте персональные данные**, если они
   нужны для демонстрации вне класса.
2. Положите в `test_samples/`, разметьте эталоны в `test_samples/labels/`.
3. Запустите замер и сохраните `report.md` (например, в `reference/` для отчёта).

> Ошибка в одном документе не останавливает замер — по каждому кейсу пишется
> свой результат или сообщение об ошибке.
